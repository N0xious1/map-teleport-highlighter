# Map Teleport Highlighter

A RuneLite plugin for new players that shows every way to teleport around
Gielinor at a glance.

It adds a small portal button next to the **zoom out** button on the world map.
Click it and every teleport destination on the map flashes, the same way icons
flash when you pick something from the world map key. Click it again to turn it
off.

## Why use it

RuneLite's built-in World Map plugin can already show teleport icons, but they
sit among every other map icon all the time. This plugin is aimed at players
who are still learning where things are:

- **One click** to light up every teleport, then one click to hide them again.
- **Tooltips written for beginners** that say what you need, not just where it goes.
- **Wilderness teleports hidden by default**, so new players don't teleport
  somewhere dangerous by mistake.
- **Pick exactly what you own**: switch on only the jewellery, capes and
  diary items you have.

## How to use it

1. Install **Map Teleport Highlighter** from the Plugin Hub (wrench icon →
   Plugin Hub → search for it).
2. Open the world map.
3. Click the portal button beside the zoom out button. It gets a gold border
   when it's on.
4. Hover any flashing icon to see what it is and how to get there.

Right-clicking the button shows **Show teleports** or **Hide teleports**.

## What it covers

285 teleports, sorted into groups you can fold open in the settings:

| Group | Count | Switches |
| --- | --- | --- |
| Spellbooks | 40 | Standard, Ancient, Lunar, Arceuus |
| Jewellery | 59 | One per item – glory, dueling, games, skills, combat, wealth, slayer and 7 more |
| Capes | 37 | One per cape – the 7 skill capes plus achievement diary, quest, music and mythical capes |
| Achievement diary rewards | 15 | One per item – Ardougne cloak, Karamja gloves, Morytania legs and 7 more |
| Travel | 86 | Fairy rings, minigame teleports, scrolls and tablets |
| Quest and reward items | 48 | Xeric's Talisman, Ectophial, obelisks and other items |

### Tooltips

| Teleport | Tooltip |
| --- | --- |
| Spell | *Varrock Teleport – Standard spellbook - Magic level 25* |
| Jewellery | *Barbarian Assault – Jewellery - Games Necklace* |
| Minigame | *Fishing Trawler – Minigame teleport (Grouping tab) – Needs: Fishing level 15* |
| Fairy ring | *Fairy ring - AIQ – Needs a dramen or lunar staff* |

### Wilderness

19 teleports land in the Wilderness, where other players can attack you. These
include the Ancient Magicks Wilderness spells, the burning amulet, the
obelisks and the Revenant Cave scroll. They are **hidden by default**. Turn on
*Show Wilderness teleports* to see them; their tooltips then carry a Wilderness
warning. Ferox Enclave counts as safe.

## Settings

| Setting | What it does |
| --- | --- |
| Show Wilderness teleports | Off by default. Overrides every group below. |
| Spellbooks, Jewellery, Capes, Achievement diary rewards, Travel, Quest and reward items | Fold-out groups with a switch for each item. Changes show straight away, even with the map open. |
| Flash | Turn off for a steady glow instead of flashing. |
| Flash speed | How long each flash lasts (default 400 ms). |
| Highlight colour | Colour of the glow (default yellow). |
| Button side | Left or right of zoom out. *Auto* puts it on the side away from zoom in. |
| Turn off when map closes | Resets the highlight each time you close the map. |
